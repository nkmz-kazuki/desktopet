# 鲸鱼娘 1.1.0

蓝紫色鲸尾少女的 Windows 桌面陪伴。轻点人物即可聊天，拖拽可移动位置；透明区域允许鼠标穿透。

## 开始使用

运行 `Whale-Girl-1.1.0-Setup.exe` 完成安装，再打开“鲸鱼娘”。右键人物选择“设置”，填写自己的 DeepSeek API Key 并保存，即可在桌面聊天。天气和时间问答可以直接使用，天气城市可在设置里修改。

- 单击人物展开或收起聊天框，同时切换为闭眼笑形象 0.8 秒。
- 睁眼和闭眼笑形象已校准身体位置，切换时只做淡入淡出，不再左右偏移或单独缩放。
- DeepSeek 生成回答期间保持闭眼笑形象，结束后恢复睁眼形象。
- 聊天框采用标准大小，不带外侧投影；标题栏保留新对话和收起按钮，状态显示绿色圆点与“在线”。人物靠近屏幕左侧时，聊天与设置面板自动出现在右侧，靠近右侧时换到左侧。人物与面板分别按屏幕工作区限位，不再由固定整块窗口限制人物移动。
- 右键人物可打开紧凑工具栏，选择设置、隐藏人物或退出；工具栏按实际尺寸避开屏幕边缘。隐藏后可从系统托盘再次打开。
- 设置支持昵称、始终置顶与开机启动。人物大小与思考强度控件已移除，升级保留原人物比例；思考固定使用最高档。
- 始终置顶会在显示、恢复窗口及电脑唤醒后重新应用，不抢占键盘焦点；关闭后恢复普通窗口层级。
- 人物可以拖到屏幕最左侧，右下角仍保持主体可见，不再允许半身出屏；脚部允许最多 20 个逻辑像素越过工作区底边，重启时自动修正越界位置。聊天、设置和工具栏仍完整留在工作区内。

人物旁的浮动问候和交互状态气泡暂时隐藏，主动问候与气泡朗读同步暂停；相关设置选项暂时隐藏，已保存的偏好和 23 句问候语保留，方便之后调整。聊天消息照常显示，设置操作失败时会在设置页提示，托盘天气在聊天框显示。

## 界面设置

界面使用与人物一致的蓝紫色。设置中的“不透明度”可分别调整各部分，数值越高越清晰，越低越透明。

聊天框、设置页、消息、输入区、问候气泡及右键工具栏统一采用新拟态风格：灰蓝色底面、内凹输入框、柔和凸起按钮，按下和键盘焦点均有清晰反馈。人物外观保持不变，聊天框与设置窗口外侧不带投影。

全界面字号统一为三档：辅助信息 12px、正文与控件 14px、标题 18px。

模型使用 12px 新拟态下拉；目录地址及“选择 / 打开”按钮也使用 12px。输入提示为“想问昵称点什么...”，昵称自动同步且不带引号。

在“模型类别”中按 Flash / Pro 系列选择 DeepSeek V4.1 Flash 或 V4 Pro，点击“保存设置”后生效。默认保留 Flash，不会因升级自动切换到 Pro。下拉支持键盘方向键、Enter 确认和 Esc 收起，未保存的选择在重新打开设置时恢复。

Flash 与 Pro 均通过真实模型 ID 发送到官方 Responses API，思考参数固定为 `max`；升级时旧档位统一迁移为最高档。[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[思考强度说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

安装和更新仅保留开始菜单入口，不再创建桌面快捷方式。

| 项目 | 默认不透明度 |
| --- | ---: |
| 人物 | 100% |
| 对话框 | 80% |
| 消息气泡 | 88% |
| 输入框 | 92% |
| 文字 | 100% |
| 问候气泡 | 50% |

调整后点击“保存设置”，下次打开时继续使用。

## 对话记录

每次提交的问答会追加到同一份 `对话积累.md`，按本地日期和提问时间分组，保留完整回答及其中的 Markdown。时间、天气问答和请求失败提示也会保存。新对话或清空聊天不会删除文件历史。

首次使用的默认位置是 Windows“文档”文件夹下的 `对话积累` 文件夹。升级时会保留已经设置的保存目录。

在设置的“对话保存目录”中，可以粘贴文件夹地址，或点击“选择”浏览文件夹，再点击“保存设置”。“打开”可查看当前保存目录。更换目录后，新问答写入新位置，原有记录仍保留在旧目录。

## 数据与存储

- 对话可选 DeepSeek V4.1 Flash 或 V4 Pro，均使用最高思考档位，应用不额外截断模型回答。两者沿用同一个 DeepSeek API Key 和现有联网搜索流程；当前桌宠输入仍为文字，不因模型具备视觉能力而自动启用图片上传。
- 模型指示要求解释文字采用纯文本、可用数字分点，不使用星号进行加粗或项目标记，也不使用 `#` 进行标题分级；代码及要求逐字引用的原文保留原样，不对回答做破坏性字符删除。
- 遇到最新事件、今年、价格、网页或明确搜索要求时，会实际调用 DeepSeek 官方 Search API，再根据返回资料回答，并附上检索来源。普通聊天也可按问题需要调用搜索。
- 搜索沿用同一个 DeepSeek API Key，无需另填密钥；搜索请求单独计费，目前为每千次成功且非空请求 0.75 美元，具体以 [DeepSeek 官方说明](https://api-docs.deepseek.com/guides/search/) 为准。
- 搜索失败、资料为空或回答未完整生成时会明确提示重试，不会把模型记忆伪装成已核实的实时资料。
- 内部安全判断及思考标记会被过滤；只有有效最终答案会进入后续聊天上下文。异常时保存简明错误提示，不保存内部区块。
- API Key 使用 Windows 加密保存，聊天内容及检索关键词发送至 DeepSeek；天气城市发送至 Open-Meteo。
- 应用设置和加密密钥保存在当前 Windows 用户的 `%APPDATA%\whale-girl` 文件夹中。
- 对话记录保存在用户选择的目录中，与应用安装目录分开。
- 本仓库不包含个人设置、密钥或对话记录。

源码仓库：[nkmz-kazuki/desktopet](https://github.com/nkmz-kazuki/desktopet)。

## 本地运行与构建

在 Windows 上安装 Node.js 与 npm 后，在项目目录执行：

```powershell
npm ci
npm start
```

运行测试与生成安装包：

```powershell
npm test
node scripts/verify-ui.cjs
npm run test:window
npm run dist
```

`npm run test:window` 仅用于 Windows，会短暂显示并自动关闭两个测试窗口，验证实际窗口层级及隐藏恢复；不读取个人设置、密钥或对话记录。

安装包输出到 `dist/Whale-Girl-1.1.0-Setup.exe`。测试使用独立临时目录，覆盖内部文本过滤、联网工具往返、失败处理、对话追加、长文本、日期分组、并发写入、保存目录切换、设置校验、浮动气泡暂停和屏幕边界。界面检查使用模拟聊天，不读取个人设置或调用外部服务，结果保存在 `dist/ui-check/`。

可选真实连接验证：执行 `npm run test:models:live`。它读取本机已加密保存的 Key，通过同一生产模型请求路径分别调用一次 Flash 和 Pro（每次最多 512 输出 tokens，会产生少量 API 用量），不发送已有聊天，不输出密钥。仅模型标识、HTTP 状态及用量摘要写入 `dist/model-api-check/results.json`，不会保存原始思考过程或响应内容。

项目目录：

- `src/`：桌宠界面、聊天、设置和对话记录。
- `assets/`：两张人物立绘和应用图标。
- `tests/`：自动化测试。
- `scripts/`：构建辅助工具。
- `dist/`：本地构建产物，不纳入源码仓库。
